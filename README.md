<details>
<summary><b>🔍 Technical deep dive: how the agents work</b></summary>
<br/>

**🔎 Research Agent**
- A **decide → act → observe** loop with `search` (DuckDuckGo), `fetch` (httpx + trafilatura) and an explicit `finish` tool, so "done" is never confused with "hit the cap"
- **Cost control outside the model**: a hard iteration cap plus a total token budget per run
- A **scratchpad** keeps context small: pages are truncated, and short summaries are re-injected every turn
- Failed fetches come back as **observations, not exceptions**, so the agent adapts; repeated queries and URLs are blocked, and every tool call is validated

**📄 RAG Agent**
- **Structure-aware chunking** that keeps the page number and section heading; title and heading are prepended before embedding
- **Sentence Transformers** embeddings in **ChromaDB**; Claude answers with **page-level citations**
- FastAPI endpoints to ingest, upload, ask and list/delete documents, plus a health check; **hash-based caching** skips unchanged files and scanned PDFs are detected
- Evaluation scores **retrieval** and **generation** separately, so you know which stage to fix

**🔌 MCP Server**
- Read-only **Model Context Protocol** server over stdio with three narrow tools: `search_docs`, `read_doc`, `list_sections`
- A custom **keyword search engine**: TF-IDF with length normalisation, an IDF threshold, stop words, word-form and British/American spelling expansion, and a phrase-match bonus

</details>

<details>
<summary><b>🔍 Technical deep dive: StyleForge AI</b></summary>
<br/>

- **AdaIN** (Huang & Belongie, ICCV 2017): a frozen VGG-19 encoder, an AdaIN layer matching channel-wise style statistics, and a decoder trained in PyTorch
- **Decoder trained for 192 epochs** with content + multi-layer style losses (Adam, learning-rate decay), resumed from saved decoder and optimizer checkpoints
- **Face preservation**: MediaPipe Face Mesh (with an OpenCV Haar-cascade fallback) builds a face mask, and a feathered blend keeps facial detail
- **Flask app**: hashed passwords, signed password-reset tokens, CSRF protection, rate limiting, per-user uploads, SQLite/PostgreSQL, Gunicorn
- **Streamlit demo**: no login, 256/384/512 px processing, before/after slider, PNG download

</details>

<details>
<summary><b>🔍 Technical deep dive: Face → Anime AI</b></summary>
<br/>

- **CycleGAN from scratch**: two 9-block ResNet generators, two 70×70 PatchGAN discriminators, LSGAN + cycle-consistency + identity losses, a 50-image replay buffer, linear LR decay
- **Data pipeline**: EDA on 500k+ raw images, corruption checks, MD5 deduplication, 80/20 splits; trained for 26 epochs
- **FastAPI** serving two models with lazy loading, in-memory caching, and checkpoints from **Hugging Face**
- **React + Vite** frontend; **Docker Compose** with a PyTorch/CUDA backend and an Nginx-served frontend

</details>

<details>
<summary><b>🔍 Technical deep dive: Churn, Segmentation & DQN</b></summary>
<br/>

- **Churn**: replaced invalid values (`?`, `Error`, `-999`), mean/mode imputation by distribution, engineered features (active days, complaint status, time per login day), RandomizedSearchCV, exported as a scikit-learn Pipeline. Membership tier, feedback and complaints were the strongest signals
- **Segmentation**: imputation, one-hot encoding, scaling, PCA to 2 components, elbow method (KneeLocator); separate scripts per pipeline stage
- **DQN**: 2×256 MLP, target network synced every 1,000 steps, YAML config, best-model checkpointing, reward curves, plus a version of the game you can play yourself

</details>
